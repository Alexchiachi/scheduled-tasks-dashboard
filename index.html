⚡ 如何在排程任務完成時自動寫入此儀表板？

在任何排程任務的 Prompt 步驟結尾，或 Python 批次腳本的最後一行，加上以下回報指令即可自動將「執行結果與說明」寫入儀表板並 Push 上線：

python3 /Users/chienchiachi/Documents/GitHub/scheduled-tasks-dashboard/tools/record_task.py \ --task "daily-gardener" \ --status "success" \ --summary "第二心智演化日誌撰寫完畢，雙基地已同步，Obsidian已成功推送到GitHub。" \ --duration "42s" \ --push

參數說明：--task (任務ID)、--status (success|warning|error)、--summary (一句話結果摘要)、--details (詳細日誌)、--push (自動提交並推送 GitHub Pages)
